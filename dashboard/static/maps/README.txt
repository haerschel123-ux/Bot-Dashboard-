Optionale Kartenbilder für die interaktive Karte.

Lege hier ein Bild pro Karte ab, damit im Dashboard ein "echter" Karten-
hintergrund statt der schematischen Karte angezeigt wird:

  ChernarusPlus.jpg   (Welt 15360 x 15360 m)
  Livonia.jpg         (Welt 12800 x 12800 m)
  Sakhal.jpg          (Welt 15360 x 15360 m)

Das Bild wird passgenau über die gesamte Weltgröße gelegt (Nordwesten = oben
links, Koordinate 0/Weltgröße). Ein quadratisches Top-Down-Bild der Karte
funktioniert am besten.

Alternativ kannst du in config.json unter "dashboard_map_tiles" eine Leaflet-
Kachel-URL je Karte eintragen (z. B. eines eigenen Tile-Servers). Ohne Bild und
ohne Kachel-URL zeigt das Dashboard automatisch die schematische Karte mit
Ortsnamen.
